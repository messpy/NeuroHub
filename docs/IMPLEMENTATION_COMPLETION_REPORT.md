### 🔧 技術仕様

#### アーキテクチャ
```
ユーザープロンプト
    ↓
SmartIntentAnalyzer (LLM解析)
    ↓
UnifiedAgentExecutor (ルーティング)
    ↓
各種エージェント (実行)
    ↓
UnifiedResponse (統一応答)
```

#### データフロー
- **UnifiedRequest**: プロンプト、ユーザーID、コンテキスト
- **解析結果**: エージェント、信頼度、理由、パラメータ
- **UnifiedResponse**: 成功/失敗、内容、メタデータ、実行時間
