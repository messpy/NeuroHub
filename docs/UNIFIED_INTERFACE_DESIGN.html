🧠 NeuroHub統一インターフェース設計書

LLM判断による自動エージェント選択システム

📋 概要

NeuroHub統一インターフェースは、ユーザーのプロンプトをLLMで解析し、最適なエージェントに自動ルーティングする次世代AIシステムです。

🎯 主要目標:
✅ ユーザーはエージェントを意識する必要なし
✅ 自然言語での統一的な操作
✅ LLMによる高度な意図理解
✅ 統一された応答形式
✅ スケーラブルなエージェント拡張

🏗️ システムアーキテクチャ

🖥️ ユーザーインターフェース層

unified_interface.py | CLI/Web/API

🔍 意図解析層

SmartIntentAnalyzer | LLMベース解析

⚙️ 実行制御層

UnifiedAgentExecutor | ルーティング・実行管理

🤖 エージェント層

各種専門エージェント | Weather/Web/MCP/Git/Command/Config...

🔄 メインフロー

1. ユーザープロンプト
→
2. LLM意図解析
→
3. エージェント選択
→
4. エージェント実行
→
5. 統一レスポンス

詳細フロー:

1. ユーザープロンプト受信 └─ UnifiedRequest作成 2. SmartIntentAnalyzer実行 ├─ LLMAgent呼び出し ├─ プロンプト解析 ├─ エージェント選択（9種類から） └─ 信頼度・理由・パラメータ返却 3. UnifiedAgentExecutor実行 ├─ 選択されたエージェント呼び出し ├─ エラーハンドリング ├─ 実行時間計測 └─ 履歴保存 4. UnifiedResponse生成 ├─ 成功/失敗ステータス ├─ 使用エージェント名 ├─ コンテンツ ├─ メタデータ（解析結果・実行時間） └─ タイムスタンプ

💡 使用例

基本的な使用方法:

高度な使用方法:

# JSON形式出力 python unified_interface.py "天気を教えて" --json # デバッグモード python unified_interface.py "コードを作成して" --debug # 実行履歴表示 python unified_interface.py --history # 特定ユーザーID python unified_interface.py "プロジェクト作成" --user-id developer001

🔧 技術仕様

コアクラス:

UnifiedRequest: - prompt: str # ユーザープロンプト - user_id: str # ユーザーID - session_id: Optional[str] # セッションID - context: Dict[str, Any] # コンテキスト情報 - preferences: Dict[str, Any] # ユーザー設定 UnifiedResponse: - success: bool # 実行成功/失敗 - agent_used: str # 使用エージェント名 - content: str # レスポンス内容 - metadata: Dict[str, Any] # メタデータ - execution_time: float # 実行時間 - timestamp: str # タイムスタンプ SmartIntentAnalyzer: - analyze() # LLMベース意図解析 - _build_analysis_prompt() # 解析プロンプト構築 - _parse_analysis_result() # 結果パース - _fallback_analysis() # フォールバック解析 UnifiedAgentExecutor: - execute() # 統一実行 - _execute_weather() # 天気エージェント実行 - _execute_mcp() # MCPエージェント実行 - _execute_llm() # LLMフォールバック

LLM意図解析プロンプト:

システムメッセージ: "あなたはプロンプト解析の専門家です。ユーザーの要求を正確に理解し、最適なエージェントを選択してください。" 解析プロンプト: "ユーザーのプロンプトを解析し、最適なエージェントを決定してください。 利用可能なエージェント: - weather: 天気予報・気象情報の取得 - web: Web検索・ページ解析・トレンド調査 - mcp: プログラム開発・コード生成・プロジェクト作成 - git: Gitリポジトリ操作・コミット・ブランチ管理 - command: システムコマンド実行・ファイル操作 - config: 設定管理・環境設定・APIキー管理 - discord: Discord Bot機能・チャット操作 - db: データベース操作・クエリ実行・データ管理 - package: パッケージ管理・依存関係解決・仮想環境 ユーザープロンプト: \"{prompt}\" 以下のJSON形式で回答してください: { \"agent\": \"最適なエージェント名\", \"confidence\": 0.0-1.0の信頼度, \"reasoning\": \"選択理由\", \"parameters\": { \"param1\": \"エージェント固有のパラメータ\" } }"
