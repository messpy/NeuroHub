🎯 プロジェクト概要

NeuroHubは、AI駆動型のスマートアシスタントシステムです。自然言語で指示を受け取り、適切なエージェントにルーティングして実行します。

目標: アレクサやGoogle Homeを超える、完全無料のオープンソーススマートアシスタント
