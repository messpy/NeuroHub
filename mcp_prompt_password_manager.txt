パスワードマネージャーの完全実装

プロジェクト名: SecurePasswordManager
概要: SQLite + FastAPI + CLIで構成されたセキュアなパスワードマネージャー

必須実装:

1. フォルダ構成
src/
├── __init__.py
├── main.py (エントリーポイント)
├── config.py (設定管理)
├── models.py (データモデル)
├── database.py (SQLiteデータベース操作)
├── encryption.py (AES暗号化処理)
└── password_manager.py (コア機能)

api/
├── __init__.py
├── server.py (FastAPIサーバー)
├── routes.py (APIルート)
└── schemas.py (Pydanticスキーマ)

cli/
├── __init__.py
├── app.py (Clickベースのメインアプリ)
├── commands.py (各種コマンド)
└── utils.py (CLI補助機能)

tests/
├── __init__.py
├── conftest.py (pytest設定)
├── test_database.py (DB操作テスト)
├── test_encryption.py (暗号化テスト)
├── test_password_manager.py (コア機能テスト)
├── test_api.py (FastAPIテスト)
├── test_cli.py (CLIテスト)
└── test_integration.py (統合テスト)

2. 技術仕様
- Python 3.12+
- SQLite3 (パスワード暗号化保存)
- cryptography (AES-256-GCM暗号化)
- FastAPI (REST API)
- Click (CLI)
- pytest + pytest-asyncio (テスト)
- uvicorn (ASGIサーバー)
- bcrypt (マスターパスワードハッシュ化)

3. 機能要件
- マスターパスワード認証
- パスワードエントリのCRUD操作
- 強力な暗号化（AES-256-GCM）
- パスワード生成機能
- エクスポート/インポート機能
- 検索機能
- バックアップ機能

4. APIエンドポイント
POST /auth/login (マスターパスワード認証)
GET /passwords (パスワード一覧)
POST /passwords (パスワード追加)
GET /passwords/{id} (パスワード取得)
PUT /passwords/{id} (パスワード更新)
DELETE /passwords/{id} (パスワード削除)
POST /passwords/generate (パスワード生成)

5. CLIコマンド
secure-pwd auth --master-password
secure-pwd add --service --username --password
secure-pwd list [--search]
secure-pwd get --service
secure-pwd update --service [--username] [--password]
secure-pwd delete --service
secure-pwd generate [--length] [--special-chars]
secure-pwd export --file
secure-pwd import --file

6. セキュリティ要件
- マスターパスワードをbcryptでハッシュ化
- 全パスワードをAES-256-GCMで暗号化
- メモリ内の機密データクリア
- SQLインジェクション対策
- 入力値検証
- セッション管理

7. テスト要件
- 95%以上のコードカバレッジ
- 全機能のユニットテスト
- API統合テスト
- CLI統合テスト
- セキュリティテスト

実装ガイドライン:
- すべてのファイルに適切なdocstringを追加
- エラーハンドリングを徹底
- ログ出力を適切に設定
- 型ヒントを使用
- PEP8に準拠
- 統合テストでモジュールインポートエラーが発生しないよう注意
