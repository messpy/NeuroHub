## 🔧 テスト実行環境

### 必要依存関係
```bash
pytest>=7.0.0
pytest-cov>=4.0.0
pytest-mock>=3.10.0
requests-mock>=1.10.0
```

### 実行方法
```bash
# 環境変数設定
export PYTHONPATH=$PWD

# 全テスト実行
pytest tests/ -v

# カバレッジ付き実行
pytest tests/ --cov=agents --cov=services --cov-report=html

# 特定テスト実行
pytest tests/agents/test_git_agent.py -v

# CLI引数テストのみ
pytest tests/ -k "cli" -v
```
